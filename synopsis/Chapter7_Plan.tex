\section{Resource & Hardware Requirements}
The project requires the following computational resources:
\begin{itemize}
    \item \textbf{Hardware}: Workstation equipped with NVIDIA RTX GPU (16GB VRAM) for model training and inference optimization.
    \item \textbf{Software Stack}: Python 3.11, PyTorch, Node.js 20+, React 19, TypeScript, TailwindCSS, Express.js.
    \item \textbf{Deployment}: Node.js runtime, Vercel / Cloud server hosting.
\end{itemize}
